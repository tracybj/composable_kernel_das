# Iteration92：不改变NT物理布局的B线性寻址

继续核对DeepGEMM raw FP8分支后，隔离B的指令寻址形式：原有structured idxen+offen versus 完整物理字节偏移offen。K阶段增量仍用SGPR soffset，4条向量读取的输出分布保持不变；256×256×128、8C4P、A batch4、统一C时序及所有barrier不变。不预排、不新增调用、不省略准备开销、不改变G或INT8×INT8→INT32无scale语义。

cache描述符分别保留physical pitch和record1024；另测线性偏移加无cache策略。record字段在线性offen中不参与逻辑行地址计算，物理偏移显式为row*pitch+Koffset。CPU122880个地址等价检查PASS；GPU300项全范围INT8/FP64边界检查PASS、70项代表shape输出/guard检查PASS。所有10个核仍214VGPR、64KB LDS、无scratch/spill，不能把本轮收益归为VGPR减少。
