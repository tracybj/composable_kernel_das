# Iteration91：原始NT输入下的A/B片上重排

针对v90外部预排改变接口/准备成本的问题，独立实现256×256×64、8-wave协同搬运/计算的Problem/Pipeline/Kernel/Epilogue。原始A[M,K]、B[N,K]直接分块搬入两套swizzled A/B LDS槽；A16KB+B16KB每槽，共64KB。没有外部格式转换或缓存。每个wave负责256×32输出，MMAC保持INT8×INT8→INT32、无scale；A读批量1/4、两种内部映射。每stage预取下一A/B槽，消费当前槽，VMEM等待加CTA barrier共同完成发布/回收。所有wave走相同协议。

CPU精确覆盖65536B LDS，294912个消费者地址检查及33种stage奇偶协议PASS。卡7上124项全范围INT8/FP64数值检查PASS，涵盖padding/tails/奇偶stage/多组/较大stride、完整输入克隆与输出guard；56项代表shape同构建输出/guard检查PASS。新核151/175VGPR、64KB LDS、无scratch/spill。三次HIP-event样本中位数，warmup2/repeat5；原WASP四个映射/record控制保留。

七组均未超过WASP控制，不提升为默认实例。生成ISA中，下一stage四条global-to-LDS预取后可见当前stage的LDS读取及MMAC；在首个MMAC前没有额外vmcnt(0)，VMEM等待保留在stage末尾，与源码协议一致。v89的cooperative核也没有v87那种额外首MMAC前VMEM等待。因此不能把两种cooperative核的慢简单归为该编译器插入问题，也不能据此定量证明某一硬件瓶颈。

相比256×256×128 WASP，新设计的stage更短，barrier频率翻倍，B增加LDS写入/读取；去掉专门producer和减少VGPR未抵消这些代价。上述是结构代价，尚未用动态counter分离各项耗时。只否定本次已测候选，不排除更合适的片上重排结构。

当前优先级：结束本轮两条无外部预排的结构验证，保留v80原始NT默认；物理权重预排v90提供6/7组相对同轮最佳raw控制的核收益，但其计时契约仍须明确，不能替代原始1178条验收结果。后续围绕权重布局、缓存访问与A/B生命周期研究，不继续无差别扫描已经无益的预取开关。所有中间证据保留。
