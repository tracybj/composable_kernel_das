# Iteration95：native与generic fallback同核的资源影响

v90 packed核198VGPR，而raw核214VGPR，先隔离generic fallback在同一kernel中可能产生的资源影响。复用v92的typed Problem/Pipeline/Epilogue，另写只接受原native域的诊断Kernel，移除generic fallback计算体；对不满足M/N256、K128和stride/span前置条件的描述符直接不计算，因此绝不注册到公开选择器，也不是可替代原接口的完整实现。生产若要使用必须先有可证明的host-domain分类；本轮未推广。

20个合法域shape×8候选共160项全范围INT8/FP64检查PASS；84项代表shape输出/guard检查PASS，原M/N/K/G保持不变。结构化寻址native核200/201VGPR，线性寻址198/199VGPR，均64KB LDS、无spill。相同完整raw核为214VGPR，说明合并fallback会影响此编译产物的资源分配，但资源下降不等同于吞吐提高。
