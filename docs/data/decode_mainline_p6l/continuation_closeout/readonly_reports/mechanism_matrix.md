# Decode 主干：证据、边界与待验证因素

当前采用计数以独立确认报告为准。发现阶段的局部赢家、静态资源节省以及 profiler 时长均不能计入 50 条稳定改善／30 条可归因跨桶。

| 研究因素 | 已验证的证据 | 结论的边界 | 当前处理 |
|---|---|---|---|
| H1 完整 M，A 寄存器／B 私有 LDS | 原窗口完成 48 个主线／短线配对，未获得整域收益 | 不能据少量短 K 收益推广到中长 K 全域 | 保留负结果；八级旧窄域的 6 条原 shape 仍属既有基线 |
| H2 A 共享／B 私有 LDS | 39 对结构实验与 74 对布局／预取因素，局部收益伴随回退 | 布局和等待的取舍需结合实际访存指令；共享／私有标签不足以预测性能 | 未采用 |
| H3 A/B 协作 LDS、两层预取 | 原窗口发现有收益，166 条七 block 确认 GM 1.053153，94 条低 CV 且七 block 均回退 >2% | 个体 28 条稳定改善／14 条归因跨桶，因整域失败不计入采用 | 整域拒绝，源与全部轮次保留 |
| 先 MMAC 后搬运的调度因素 | 新窗口 compact19／wide14 GM 1.015421／1.031505，直接调度控制未形成广泛收益 | 两组代表集合不同；寄存器下降不等于时间收益 | 未采用 |
| K64 双槽 | 19／14 代表 GM 1.081196／1.136593；ID805 同八 wave 控制中 SALU/wave 1303→680，驻留约 7.38→7.21，正式回退 15.3% | wait、LDS 冲突及资源同时变化，单个计数不能给出完整因果 | 淘汰该 K64 因素 |
| K32 N256 两／三槽 | 相同 19 代表 GM 1.042323／1.034429；全部全输出与 guard 通过 | 部分 shape 更快，整域仍有回退；D3 不普遍改善 | 未采用 |
| N256 wave 内 B 复用 | D2／D3 GM 1.015139／1.034028；ID805 同深度代码 VGPR 168→128、LDS 指令/wave 1316→1060，实测驻留约 6.697→6.688 | 减少寄存器与 LDS 指令未充分转化为整体收益；M≤16 两版本机器码相同 | 未采用；保留匹配分工控制 |
| N128 低 LDS 与固定自动属性规则 | 相同 23 代表 pure／auto GM 1.173542／1.089295；ID805 几何控制驻留 6.695→13.563，LDS/SALU 总数约增 48%/47%，正式回退 26.04% | N 宽、CTA、wave 分工与 LDS 足迹耦合；PMC HBM 是整个 dispatch 的重放计数，不能认定 B 单独重复 | 两个预登记规则均拒绝，无新盲测 seed |
| N128 四 wave 完整 M 与 B 复用 | 35 资格、27 个三轮配对通过全输出／guard；16 实际代表 GM 1.183817，1 条改善 >2%、13 条回退 >2%；VGPR 59/83/131 | SQTT 原计划 8 对仅完成 2 对，ID686 多个 CU 稀疏、CU15 应用 rc134 中止；原因未充分定位，不能称为已确认 MKFD | 单一 M17..64 的 96 原 shape／53 弱项规则拒绝；不抽新 seed，不按赢家 ID 分派；4 份有效 perf 及失败原样保留 |
| 固定结构的 A-load SLC 位修订 | 正式 gfx936 三个完整指令体仅各 14 条 A-load 的 0x20000 位改变；6 个双目标 shader 资源不变。35 资格、23 个三轮配对、8 份有效 SQTT；16 代表 GM 1.124657，2 条改善 >2%、12 条回退 >2% | 旧／新6035跨构建耗时只作诊断。ID620 HBM 计数降低、计算利用率改善后仍有大幅回退；单项计数下降不构成充分因果解释 | 原固定 96／53 属性域拒绝；未抽新 seed，原 P6k 不替换 |
| host 优先策略的无效回退检查 | 精确抽取适配层的 322845 项 CPU 对照，其 status／instance／reason 全等；1766 个 shader 的机器码／资源全部不变；35 资格和 10 三轮配对通过 | 7 个回退控制和 3 个主线代表用于修复检查；短控制仍有高 CV，CPU 工作减少不能等同明确 GPU 收益 | 保留必要修复，不计作新流水或性能目标贡献；不更换原表方案 |
| 固定结构的两套 FP32 累加缓冲 | 正式 M16/32/64 的独立 MMAC 目标向量 2/4/8→4/8/16，MMAC 数不变，VGPR 67/99/163，零 spill；35 资格、23 三轮配对及 8 份有效 SQTT。16 代表 GM 1.123799，2 条改善 >2%、11 条回退 >2%、3 条在 ±2%，2 高 CV | FP32 求和顺序改变，原精度阈值全输出通过；无法据独立链翻倍确认实际重叠收益，旧单累加跨构建时间只作诊断 | 同一 96／53 属性规则拒绝；不抽新 seed，不启动不合格候选的扩围确认 |

上述三种 H1/H2/H3 是所有权结构假设。K 粒度、深度、N 块宽、wave 分工和调度是受控因素，不能按实例数量声称新增了同等数量的主干架构。

短 K／低 G 两项原型已在原窗口完成精度及三轮实验并得到负面结论；旧 short 独立确认没有执行，不能写成已通过或已失败。原始三项研究的历史证据见 [原窗口收尾报告](/workspace/composable_kernel/docs/data/decode_mainline_p6l/final_closeout/closeout/README.md)。其中“最后原型仅编译”的描述属于旧截止时点；它已在本续研窗口作为 phase 实验完成验证，两个时点应分开阅读。

所有续研 CK 对照均在 GPU4、同一阶段二进制内比较。各阶段成绩保留各自二进制／epoch；完整汇总见 [stage_summary.csv](stage_summary.csv)。没有跨构建逐 shape 取最快值。原 P6k 和冻结 GPU0 Native GroupGEMM BLAS 保持不变，新同卡 Native 诊断单列 R_live。

Profiler 证据使用实际目标 dispatch、捕获代码、SQTT 与计数；Source 定位循环依赖，Wavefronts 查看加载／DS read／MMAC／wait 的重叠。不同 wave 的累计时钟不能相加作为 kernel 墙钟。XCompute GUI 未在本机运行；用户已说明暂未查看第 13 批、先继续实验，GUI 观察仍未确认。

本页为诊断索引；全部阶段的实际状态以对应 discovery_analysis、profile manifest 和独立确认报告为准。优先策略的回退检查修复属于既有 host 固定开销因素，不计为第四种所有权架构，也不计为新短 K kernel 假设。
